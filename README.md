# Stop picking models

What IBM Bob is, and how its model router decides which AI model handles each task. Part two of a short, visual series on enterprise AI.

Read it at **https://subramaniamj.github.io/ibm-bob-model-router/** (GitHub Pages), or open `index.html` locally.

## What's in the folder

| Path | What it is |
| --- | --- |
| `index.html` | The article. Carbon-style light theme, with a dark mode toggle. |
| `assets/css/article.css` | The page styles (shared with part one). |
| `assets/infographics/` | PNG exports of the quote and all five figures, ready for LinkedIn. |
| `assets/img/cover.png` | 1920 × 1080 cover image. |
| `assets/img/social-card.png` | 1200 × 627 link preview image. |

## Publish on GitHub

**GitHub Desktop:** File → New Repository.
- Name: `ibm-bob-model-router`
- Local Path: the **parent** folder, `My Articles - Linkedin` (not this folder, or you'll get a nested copy)
- Leave README, Git ignore and License empty, then Create Repository → Publish repository (untick "Keep this code private").

**Turn on GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / root.
